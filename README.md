# Online Course Dropout Predictor 🎓

This machine learning project predicts which students are at risk of dropping out from an online learning platform based on behavioral and performance data.

## 🔧 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 📁 Dataset Features
- `video_watch_percent`
- `quiz_score_avg`
- `assignments_submitted`
- `num_logins`
- `dropout` (label)

## 📈 ML Approach
- Trained Decision Tree and Logistic Regression models
- Evaluated using confusion matrix and classification report
- Visualized correlation heatmaps and model performance

## 🚀 How to Run
1. Open `dropout_predictor.ipynb` in Jupyter or Colab
2. Install requirements: `pip install -r requirements.txt`
3. Run all cells to preprocess data, train, and evaluate models
